## 2026-05-07 - Language Switcher Accessibility Refactor
**Learning:** When using custom text-based Language Switchers, wrapping options in a `role="group"` with an `aria-label` provides essential context for screen readers. Replacing generic `<span>` + `onClick` with semantic `<button type="button">` correctly exposes interactive elements, and `aria-pressed` combined with `focus-visible` utility classes (e.g. `focus-visible:ring-2 focus-visible:ring-zinc-950`) ensures clear state and robust keyboard navigation. Also decorative characters (like `/`) must have `aria-hidden="true"` so screen readers don't misinterpret them.
**Action:** Use semantic `<button>` instead of `<span>` for interactive elements, apply grouping roles, dynamic aria states, and avoid adding custom CSS by relying on existing Tailwind `focus-visible` utility classes.
