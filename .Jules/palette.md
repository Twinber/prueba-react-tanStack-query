## 2024-05-13 - Language Switcher Keyboard & Screen Reader Accessibility
**Learning:** Custom interactive elements (like language toggles built with `<span>` and `onClick`) are completely invisible to keyboard users and lack context for screen readers. Using semantic `<button>` tags within a `role="group"` container natively solves keyboard focusability and groups the options properly. Additionally, dynamically setting `aria-pressed` based on `i18n.resolvedLanguage` effectively communicates the active state.
**Action:** When building or auditing custom toggles, always ensure they are built with semantic interactive elements (`<button>`), wrapped in logical groups (`role="group"`), and utilize dynamic ARIA states (`aria-pressed` or `aria-current`) to communicate active selections. Hide visual separators (like `/`) with `aria-hidden="true"` to prevent screen reader noise.
