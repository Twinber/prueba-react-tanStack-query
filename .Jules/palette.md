## 2024-05-18 - Language Switcher Accessibility
**Learning:** Found a common anti-pattern where functional language switchers are implemented using clickable `<span>` elements instead of semantic `<button>` tags, completely bypassing native keyboard focus management and screen reader accessibility. Additionally, inline separators like `/` without `aria-hidden="true"` disrupt screen reader continuity.
**Action:** Always replace `onClick` span elements with semantic `<button>` tags for interactive elements. Enforce wrapping related toggles in a `role="group"` container with `aria-label`, adding `aria-pressed` states derived dynamically from i18n context (`i18n.resolvedLanguage || i18n.language`), and explicitly marking visual separators as decorative to ensure a seamless, accessible navigation experience.
