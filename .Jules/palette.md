## 2025-02-27 - Semantic Multi-Select Toggle Groups
**Learning:** Building language switchers with plain `<span>` tags wrapped in an `onClick` handler breaks keyboard accessibility entirely, failing to place them in the tab order or provide focus rings. Without a grouping mechanism (`role="group"`), screen readers announce each toggle in isolation without context of the whole control.
**Action:** When implementing custom stateful switches with multiple distinct options (like Language or Theme switchers), replace generic elements with semantic `<button>` elements, wrap them in a container with `role="group"` and `aria-label`, explicitly manage the active state using `aria-pressed="true"`, and ensure purely decorative text (like the `/` separator) is hidden via `aria-hidden="true"`.
