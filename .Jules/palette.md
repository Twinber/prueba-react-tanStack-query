## 2024-05-18 - Language Switcher Component Accessibility Update
**Learning:** Using semantic `<button>` elements over `<span>` for UI toggles ensures proper keyboard interaction. Screen readers require grouping toggles with `role="group"` and `aria-label`, identifying the active state via dynamic `aria-pressed`, and hiding purely decorative text separators with `aria-hidden="true"`. To safely determine the current locale in react-i18next and trigger React render cycles reliably for the UI state, use `i18n.resolvedLanguage || i18n.language`. Focus states (`focus-visible:ring-2 focus-visible:ring-zinc-950 focus-visible:ring-offset-2`) are necessary for keyboard user visibility.
**Action:** When implementing custom toggle inputs, prefer semantic `<button>` inside an explicitly labelled grouped container. Hide purely visual elements and communicate the selected toggle using `aria-pressed`. Maintain standardized ring utilities for focus visibility.
