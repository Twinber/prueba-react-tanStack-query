## 2024-05-24 - Language Switcher Custom Toggles
**Learning:** In custom toggles like a Language Switcher using separate items for each option, implementing options as `<span>` tags with `onClick` handles is an accessibility anti-pattern because they lack semantic meaning and keyboard accessibility (focus, tab, enter/space interaction). Additionally, visual separators between options (like `/`) can cause confusing announcements by screen readers if not hidden.
**Action:** When implementing custom toggle choices (e.g., Language Switchers), use semantic `<button type="button">` tags. Apply `focus-visible` outline styles for keyboard navigation. Use `aria-pressed="true/false"` to convey the active state, wrap the options in a container with `role="group"` and `aria-label`, and hide any decorative text separators using `aria-hidden="true"`.
