## 2024-05-06 - Language Switcher Accessibility
**Learning:** For custom stateful switches like Language Switchers, assigning dynamic ARIA attributes like `aria-pressed="true"` communicates the active state to screen readers correctly. The visual `"/"` separators should also be explicitly hidden using `aria-hidden="true"`, and the toggles should use a `<button>` semantic element (instead of non-interactive `<span>` tags with click handlers) and be wrapped in a `role="group"` with an `aria-label`.
**Action:** Consistently apply `role="group"` on custom multi-option toggles, use semantic buttons with visual focus (`focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-zinc-950 focus-visible:ring-offset-2`), and hide visual decorations with `aria-hidden="true"` throughout the project.
