## 2024-03-24 - Language Switcher Accessibility
**Learning:** Replacing non-interactive tags (like `<span>`) with semantic `<button>` tags for elements acting as toggles immediately resolves inherent keyboard navigation and screen-reader semantics issues. Additionally, visually decorative text (like a slash separator between languages) needs `aria-hidden="true"` to prevent distracting out-of-context screen reader announcements. Using `role="group"` and `aria-label` provides necessary context to the grouped toggle buttons.
**Action:** Always prefer semantic interactive tags (`<button>`, `<a>`) over `<div>` or `<span>` with click handlers. Ensure custom toggles have `aria-pressed` or `aria-current` dynamically tied to their active state, and use `aria-hidden="true"` on non-informative visual separators.
