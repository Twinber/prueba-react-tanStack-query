## 2024-11-20 - Accessible Language Switchers in React
**Learning:** React `onClick` handlers on non-interactive elements (like `<span>`) fail screen reader and keyboard accessibility checks. When implementing custom Language Switchers, it's crucial to combine semantic `<button>` elements, wrap them in a `role="group"`, and use dynamic properties like `aria-pressed={isActive}` (often derived via `i18n.resolvedLanguage || i18n.language` in `react-i18next`) to clearly communicate the active state. Also, decorative text separators (like `/`) must be explicitly hidden from screen readers using `aria-hidden="true"`.
**Action:** Always use `<button>` for interactive language options. Wrap multiple choices in `role="group"` with an `aria-label`. Use `aria-pressed="true"` for the currently selected language and verify keyboard focus (`focus-visible`) styling is applied.
