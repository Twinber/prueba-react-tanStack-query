## 2024-04-26 - Semantic Language Switcher
**Learning:** Replaced non-interactive `<span>` tags using `onClick` in `LanguageSwitcher.tsx` with semantic `<button>` elements. Utilizing `aria-current` dynamically based on `i18n.resolvedLanguage || i18n.language` provided excellent contextual state to screen readers. Grouped interactive options with `role="group"` and `aria-label="Language selection"`, while hiding decorative elements (`/`) via `aria-hidden="true"`.
**Action:** When implementing custom interactive elements (like toggles or switchers), ensure they use `<button>`, provide focus-visible outlines matching the design system, define an accessible group container if multiple options exist, and leverage ARIA states (like `aria-current` or `aria-pressed`) tied directly to active application state.
