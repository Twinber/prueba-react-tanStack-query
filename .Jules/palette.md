## 2024-05-18 - Language Switcher Keyboard Navigation
**Learning:** React Query Devtools can inject DOM nodes that cause strict mode errors in Playwright verification scripts if generic locators (e.g. `span[aria-hidden="true"]`) are used. Similarly, custom toggle UI lacking semantic HTML tags blocks native keyboard accessibility patterns like Tab navigation.
**Action:** When implementing custom toggles or multi-option selectors (like a Language Switcher), always use semantic `<button>` elements, wrap them in a `role="group"`, and rely on dynamic `aria-pressed` attributes. Avoid relying solely on `<span>` tags with `onClick` handlers. When writing Playwright tests, prefer highly specific locators like `get_by_role` with `exact=True` or text-specific selectors `span:text-is("/")` to avoid unintentional React Query Devtool matches.
